# Shubh Caterers — Pure Veg Catering Website

A multi-page static marketing website (no framework, no build tools, no dependencies) built from the homepage reference in `public/homepage UI.png`.

## Run locally

```bash
python -m http.server 8080
```

Open `http://localhost:8080`. All links are relative, so the site also works from any sub-folder or host.

## Edit content & regenerate

Pages are generated by Python (needs Pillow):

- `site_data.py` — business details, 11 services, the full menu (cleaned from `public/catering MENU.xlsx`), gallery, videos, testimonials, FAQs
- `templates.py` — shared header, footer, enquiry form, page hero
- `icons.py` — inline SVG icons
- `generate.py` — page layouts

```bash
python generate.py
```

## Assets

- `assets/css/` — `base.css` (tokens, buttons, header/footer), `sections.css` (home sections), `pages.css` (inner pages)
- `assets/js/main.js` — hero slideshow, pinned horizontal menu, parallax, zoom band, sticky stacks, lightbox, carousel, filters, scroll-spy, WhatsApp enquiry form
- `assets/img/` — WebP images (`*-sm.webp` = 640px mobile versions) and video posters
- `assets/video/` — web-optimised copies of the six client videos (`event-N.mp4`) and short muted loops (`event-N-loop.mp4`)
- `assets/brand/` — transparent logo and favicons

## Enquiry form

There is no backend. Submitting the form opens WhatsApp (9595956709) with the enquiry pre-filled; an email link with the same details is also offered.

## Before launch

1. Replace `https://shubhcaterers.example` in `site_data.py` (`BUSINESS['domain']`), then run `python generate.py` to refresh `sitemap.xml` and `robots.txt`.
2. Confirm 9595956709 is the WhatsApp number (change `BUSINESS['whatsapp']` and `WHATSAPP_NUMBER` in `main.js` if not).
3. Confirm the three testimonials (taken from the reference design) are genuine client reviews.
4. Do not upload `public/` (source videos are ~35 MB); everything the site needs is in `assets/`.

## Deploy on Netlify

`netlify.toml` builds with `npm run build` (copies only the site files into `dist/`, leaving out `public/` and the Python sources) and publishes `dist/`.

- **Git deploy:** push the repo, then in Netlify choose *Add new site → Import an existing project*. Build settings are read from `netlify.toml`.
- **CLI deploy:**

```bash
npm install
npx netlify login
npm run deploy:preview   # draft URL
npm run deploy           # production
```

Run `python generate.py` first if you changed `site_data.py`, `templates.py` or `generate.py`, since the generated HTML is what gets deployed.
