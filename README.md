# Shubh Caterers — Pure Veg Catering Website

Live: **https://shubhcaterers.in/** · Hosting: **Netlify** (site `shubh-caterers`, auto-deploys from GitHub `pv-webservices/shubh-caterers-static`, branch `main`) · DNS: **GoDaddy** · Email: **Zoho Mail** (info@shubhcaterers.in)

A static multi-page site generated by a small Python script, plus one Netlify Function that emails form enquiries through the client's own Zoho mailbox.

## Folder structure

```
generator/            Python page generator (needs Pillow)
  site_data.py        business details, services, menu, gallery, testimonials, FAQs  ← edit content here
  templates.py        <head>/SEO/JSON-LD, header, footer, enquiry form, responsive <picture>
  generate.py         page layouts, titles and descriptions → writes pages/
  images.py           source-files/ masters → web images, favicons, OG cards
  icons.py            inline SVG icons
pages/                generated HTML (committed; one folder per URL, e.g. pages/about/index.html → /about/)
assets/
  css/                site.css (entry) imports fonts, base, sections, pages, forms
  js/                 main.js (entry), enquiry-form.js, enquiry-rules.js (shared with the server)
  fonts/              self-hosted Poppins, Playfair Display, Great Vibes (latin woff2, OFL)
  images/             generated AVIF + WebP at 480/800/1200/full widths
    brand/ food/ venues/ events/ team/ video-posters/ og/
  video/              web-encoded event videos and muted preview loops
static/               favicons + site.webmanifest (copied to the site root)
netlify/
  functions/enquiry.mjs   POST /api/enquiry
  lib/                    handler, email builder, rate limiter, no-JS fallback page
scripts/
  build.mjs           builds dist/: bundles + fingerprints CSS/JS, sitemap, robots.txt, _redirects
  audit-seo.mjs       technical SEO audit of dist/
tests/
  unit/               node:test — handler (mocked mail transport) and validation rules
  e2e/                Playwright — every page (axe, console, images), layout, keyboard, form states
source-files/         full-resolution masters — NOT deployed
  brand/              original logo (JPEG) + transparent logo master
  images/             full-size photo masters (same folder names as assets/images)
  video/              original client videos
  reference/          menu spreadsheet, homepage design reference, business card
docs/                 GOOGLE-SEARCH-CONSOLE.md, EMAIL-SETUP.md
```

## Commands

| Command | What it does |
|---|---|
| `npm install` | install build/test tools (Node 22+) |
| `npm run images` | rebuild web images, favicons and OG cards from `source-files/` (Python + Pillow) |
| `npm run generate` | regenerate all HTML into `pages/` (Python + Pillow) |
| `npm run build` | build `dist/` (this is what Netlify runs) |
| `npm run dev` | build, then serve `dist/` with redirects, headers and the function at http://localhost:8888 |
| `npm run typecheck` | TypeScript check of all JS (JSDoc types) |
| `npm test` | unit tests (no email is ever sent) |
| `npm run audit:seo` | SEO audit of `dist/` — must report 0 issues |
| `npm run test:e2e` | Playwright browser tests (form endpoint intercepted) |
| `npm run check` | all of the above in order |

First-time Playwright setup on a new machine: `npx playwright install chromium`.

## Editing content

1. Edit `generator/site_data.py` (or `generate.py` for titles/descriptions/layout).
2. New or changed photos: put the full-size master in `source-files/images/<folder>/<lowercase-hyphenated-name>.webp`, then `npm run images`.
3. `npm run generate` → `npm run check` → commit `pages/`, `assets/` and your source changes.

## Deploy

Netlify builds automatically on every push to `main` (`npm run build`, publish `dist/`, functions from `netlify/functions`).

1. `npm run check` must pass.
2. Commit and push to `main` → Netlify deploys in ~1 minute. Pull requests get a deploy preview.
3. Check the live site (see the checklist in `docs/GOOGLE-SEARCH-CONSOLE.md`).

Manual alternative: `npx netlify login`, then `npm run deploy:preview` (draft URL) or `npm run deploy` (production).

**Form email** needs Netlify environment variables and Zoho DNS records — see [docs/EMAIL-SETUP.md](docs/EMAIL-SETUP.md). Keys are listed in `.env.example`; never commit real values.

## URLs

Clean lowercase URLs with a trailing slash (`/services/wedding-catering/`). Old `*.html` URLs and `/index.html` 301-redirect to them (`dist/_redirects`, generated by `scripts/build.mjs`). `/thank-you/` and the 404 page are `noindex` and not in the sitemap.
